# 内容保持型视觉中层剪枝：冻结确认结果

本文件为本次已完成实验的结果快照，持续进度仍以实验总纲为准。未改写此前综合汇报。

## 1. 研究问题与改动

目标是在删掉一半视觉位置的同时，比固定隔点选择保留更多有用信息，并保留中层提前删点的实际计算收益。模型权重没有训练；本轮只检验一个固定的免训练选择器。

输入真实成对帧，经288×384画布处理后，视觉网络有432个patch、108个完整2×2合并组。前12层正常处理；中层方法选择54组，把后12层的输入实际缩为216个patch，最终送入语言模型的每帧对表示从108减至54 Token。保留原位置坐标，不把不相邻位置冒充连续网格。

选择器先对每组四个patch取均值，计算：

```text
空间分数 = 1 - cosine(当前组, 当前全部组均值)
时间分数 = 1 - cosine(当前组, 前一真实帧对同位置组)
总分 = 0.5 × 空间分数 + 0.5 × 时间分数
首帧对只使用空间分数
9×12组网格按2×2小区分组，每区保留最高分一组，共30组；再补全局最高分24组
```

它倾向保留与全局不同、相对前对有变化的位置，但这些属性不等于任务相关性。它不看问题、答案或未来画面。每视频独立重置，仅额外保留一份108×1024的FP32中层描述子，442,368字节，即432KiB。

后置内容组也使用相同中层分数，只是在完成全部视觉层后再选择；因此能分别观察“选择哪些位置”和“何时停止计算”的影响。

## 4. 结果判断与本轮取舍

本次原顺序主结果中，内容与固定中层选择都是651/959；两者各救回54题、丢失54题。四轮汇总内容多16次正确，平均差值的来源区间仍跨零，因此没有证明总体正确率稳定提高。相对完整视觉，内容少29题，约3.02个百分点；不能称无损压缩。

同时，内容选择的稳定性有明确描述性收益：四轮全部答对517题，对固定492题净增25题，具体为救回73、丢失48；答案内容四轮一致620题，对固定588题净增32题，具体为新增97、失去65。它不是零作用，主表同分也不能掩盖这种变化；这些端点不能代替预先指定的原顺序主成绩。

题型表现进一步说明它改变了保留信息的偏好：预测推理固定62/103、内容72/103；计数固定39/104、内容30/104。对象、事件、属性也各有得失。这些是固定确认后的描述性分组，不据此为每类问题调整超参数，也不直接把错误归为底座能力或某一种位置丢失。

完整视觉在本集680/959、纯文字447/959；相同提问下加入视觉净多233题，说明本集视觉输入确有整体贡献。它不证明每次正确都依赖画面，也不能把本集较高分数推广到S-EMBER的长期细节与计数。

本轮保留内容选择作为可解释候选与稳定性对照，暂不加入默认路径；当前免训练公式的验证到此完成，不在本集继续扫权重、层数、比例或按题型调参。旧固定剪枝保留为更便宜的对照，完整视觉继续作保真参考。若后续研究可训练的视觉重要性，应单列新方案与独立验证，以保持未剪枝模型已有能力为目标，不承诺补足其原本不会的动作或计数。

成本结论须与外部质量严格区分：6.71%完整处理节省来自S-EMBER独立成本面板，当前StreamingBench确认共享编码，没有独立端到端成本测量；不能将二者拼成同一数据分布上的实测质量—成本曲线。内容法在旧成本面板比固定中层多约1.08%耗时且多432KiB状态，稳定性收益是否值得这份开销仍是应用取舍。

## 5. 行为与选择记录

V0解码集成回归480条新回答逐项复现原单线程的输入、生成及查询状态。这支持在该固定面板上接入线程优化，但不是所有媒体均可解码的保证。

另在预先固定4个开发视频的12个位置记录实际选择。每个目标以紧邻前一帧对初始化时间分数，后置/中层选择ID一致；后置输出与完整特征gather数值对齐。中层删点会改变剩余层的上下文，因此其特征不应假设等同于完整编码后截取。12例中内容法没有比固定法选择更多全黑单元；这项检查不能判断是否保住了题目所需物体。
