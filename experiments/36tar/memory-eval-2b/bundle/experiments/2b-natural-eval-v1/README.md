# 2B固定自然视频评测

本目录是独立实验适配，不改变合作仓库的默认入口，不训练权重。持续进度只看根目录《实验总纲.md》。

## 比较什么

沿用0.8B阶段已固定的171题、67视频及逐帧RGB/PTS身份：公开74题、已打开47题、新来源已审核50题。这些集合不再称作新的最终留出。原前两组1 FPS，后一组0.5 FPS，192×256等比补边；完整原题与选项不变，最多生成8 Token。

| 条件 | 实际提供的视觉证据 | 用途 |
|---|---|---|
| native_original | 原实现读取全部采样视频 | 原模型基础参照 |
| full_pairwise_reference | 全部独立编码帧对，完整保留 | 记忆策略的共同参照 |
| M0 | 最近8对，最多384视觉Token | 简单短期窗口 |
| M1 | 近期4对与历史4个真实代表 | 固定时间层级长短期对照 |
| M2 | 近期4对、开事件根、闭事件森林 | 有损合并候选，最多384视觉Token |
| text_only | 原题和选项，没有视频 | 语言线索/捷径检查 |

M1的合并范围只是来源范围，代表本身不包含该范围的全部画面。M2固定沿用旧事件阈值0.047536224126815796，不假定它对2B最优。M2保留的坐标是合并目的Token坐标，是既有适配方案，不宣称压缩无损。

## 移植边界

唯一运行入口是`evaluate.py`；`runtime_bridge.py`明确选择集群项目中的原实现或流式实现。原生和流式在独立进程顺序加载真实2B。完整pair读取和候选共用同一编码、读取器和生成规则。`features.py`、`forest.py`只把特征宽度检查从1024放宽至2B实际2048；合并、质量、坐标和预算规则不变。其余旧helper按字节复用，来源摘要在`reuse_provenance.json`。这些helper的历史CLI不作为2B入口。

CPU先核实际视频SHA、采样RGB/PTS、原生和逐对处理像素一致、全部问句和上下文长度、微型混合网络读取，以及2048维银行与问答隔离。CPU通过不代替真实权重准确率。

## 资源与解释

GPU只在Slurm已分配的A800上运行，FP32，不安装新依赖或下载新权重。预载空闲RAM至少12 GiB、GPU至少16 GiB；进程采样RSS上限20 GiB，GPU allocated上限24 GiB。该RSS检查是问答后采样，瞬时峰值由24 GiB Slurm内存限额约束。每worker最多1800秒，外层还受用户窗口绝对截止约束。最多两次串行载入、1026回答、8208生成Token。

这轮是完整因果前缀顺序逐对编码、更新外部有界记忆后的独立片尾问答。它没有增加摄像头、墙钟连续播放、主会话reset或跨轮聊天的验收证据。完整参照缓存另外计量，不能把本实验所有存储说成384 Token。

严格单选项评分为主；首字母只诊断输出格式。F/T观察题为主、C背景因果题为辅，按保守视频源组做配对差值和2000次bootstrap。三组分别报告，不按模型正确率删题。和0.8B比较时只使用输入与预算匹配的同名条件；新50里的0.8B recent4不是本轮M0，不互相冒充。

`prepare_local.py`生成本轮输入与锁；`cluster_io.py`只做有界传输/CPU；`submit_and_observe.py`负责一次明确授权提交和自有作业观察/证据取回；`analyze_local.py`只在本地读取评分答案。清单路径统一POSIX，首轮Windows反斜杠故障及修复前锁保留。

## 本轮诊断与可选读取结构

`diagnose_early9.py`使用D25全前缀审核后固定的九道旧事件题，比较完整四旧对、压成48、各自加相同近期四对，以及近期/文字/完整重放。窗口人工指定，不是检索候选。`analyze_early9.py`保留严格主分，另有事后格式审计；不能把正确选项附解释造成的格式损失写成压缩语义损失。

`temporal_route.select()`是本轮唯一R0候选：固定时间词触发旧节点分支，否则全部M2，无旧节点回退全部。`evaluate_route.py`四臂共用原171题和同一森林；旧/近期读取最多192，全部/路由最多384，实际读取量各报。真实分支输入与生成和M2重放均需核验。结果快照在根目录《2B自然视频与长短期记忆首轮结果.md》，持续决定仅总纲。

冻结协议明确本次窗口截止。未来复验须新建独立协议/输出目录、更新预算及资源授权，不能覆盖旧运行，不能把这些一次性提交器当成永久GPU许可。`audit_delivery.py`只读复算本轮1773条回答、数据/源码锁及分支一致性；`final_remote_audit.py`只查看授权项目和已知自有作业。交接备份排除视频、图片、权重、环境和密钥。
