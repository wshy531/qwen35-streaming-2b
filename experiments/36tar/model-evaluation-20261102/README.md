# 2B模型侧阶段交接 · 2026-11-02

从 [搭档交接.md](搭档交接.md) 开始阅读。其中第3节给出本次300题五方法完整结果，第4节解释辅助裁判能区分什么。历史基线见 [PR #6](https://github.com/wshy531/qwen35-streaming-2b/pull/6)。

在本目录运行以下命令，用Python标准库从公开的逐题对错重新统计两张内容表、20组配对得失及23题辅助表，并校验关键源码快照。

```sh
python -I -B verify.py
```

| 路径 | 用途 |
|---|---|
| results/outcomes.csv | 每题一个匿名标识、一个来源标识以及五组内容对错。1表示该组选择官方答案，0表示未命中。无法解析的数量在主表另列。 |
| results/content.json | 两数据集分报的正确数、视觉及总输入Token、输出截断、按来源重采样区间与辅助判读触发标记。 |
| results/judge_records.json、judge_tables.json | 23个问题115份匿名解释的判断字段与汇总。题目标识与主表一致，可交叉分析。 |
| results/provenance.json | 完整性回执、集群作业编号、输入清单及原始输出指纹，用于有授权数据的队友对齐。 |
| results/*.md | 基线、训练退化与修订、事件银行和读取方式比较的阶段复盘。各文件“下一步”反映当时的实验顺序。 |
| source/、source_manifest.json | 本阶段关键实现与相对项目根目录的原始位置。训练、推理及判读在共享项目原目录运行，公开目录内的独立复核入口为上面的verify.py。 |

模型侧归档只增加个人实验目录。端侧成本应以设备上的完整路径另测。本次各方法共享/重放的处理时长只用于作业核算。
