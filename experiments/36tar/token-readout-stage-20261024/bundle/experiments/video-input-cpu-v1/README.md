# V0：固定输入的有界多线程解码对照

本目录比较两种 PyAV 视频输入配置，不加载模型。持续进度以项目根目录 `实验总纲.md` 为准；结果以 `runs/video_input_cpu_prepare_20261024_01/` 的冻结回执为准。

## 范围与控制

- `slice1`：`thread_count=1`、`thread_type=SLICE`。
- `auto4`：`thread_count=4`、`thread_type=AUTO`。
- 两项配置一起改变，不能把结果归因于单一线程数。
- 固定已有六段长视频，以及 natural171、T98 中各一段短视频；每段两种配置、各两次重复，以 AB/BA 顺序运行，共32个顺序独立 CPU 进程。
- 媒体、采样帧编号、归一化真实 PTS、等比补边 RGB SHA、查询时刻和既有长视频提交快照全部固定。
- 长源运行到 EOF；短源在既有最后采样帧停止，保留原先显式的查询孤帧补齐规则。
- 不缓存整个视频，不修改采样率、画布、问题、模型或旧 GPU 实验脚本。

## 文件与入口

| 文件 | 职责 |
|---|---|
| `source.py` | 懒解码、逐帧身份检查、有限 RGB 缓冲及线程配置 |
| `consume.py` | 重放已有查询协议，检查提交前缀和未来画面隔离 |
| `prepare.py` / `freeze.py` | 一次性准备清单、冻结执行依赖 SHA |
| `preflight.py` | 首帧、取消清理、单次消费及配置矩阵检查 |
| `worker.py` / `run.py` | 单 case 守卫、顺序子进程与唯一运行回执 |
| `analyze.py` | 完成后审计32份回执并汇总两次重复的中位数 |
| `integration.py` | 显式传入 `decoder_config` 的可选固定输入适配器 |
| `integration_check.py` | 计时结束后，用真实共享帧包类型检查两种入口及取消 |

`integration.py` 的 `long_source(env, path, group, decoder_config=...)` 返回与既有 `frames / take_pair / close` 协议相容的来源；`short_packets(...)` 提供短源包迭代。两者现在默认`auto4`，可显式指定`decoder_config='slice1'`使用单线程。`env` 只需提供 `FramePacket` 类型，构造参数为帧编号、实际时间、RGB 数组和接收序号。`group` 必须是冻结的规范输入清单。

默认提升依据为本轮32次输入对照，加上218327真实2B运行的112来源/7913采样像素和PTS核验及完整视觉303旧参照复现。额外CPU/解码缓存与首帧延迟边界仍存在；不承诺任意媒体、摄像头或端侧均无代价。原`integration_check.json`对应提升前入口，提升后的核验单独保存在`runs/video_input_default_enable_20261024_01/`，不覆盖旧回执。

这是**固定输入评测适配器**，不是任意文件或摄像头的通用采样器。新评测须显式选择配置并重新冻结执行依赖；不得在旧 GPU 基准运行中替换源文件后继续沿用旧 SHA 回执。

## 计时、内存及因果边界

`input_wall_seconds` 包含媒体完整性校验、容器打开、顺序解码、抽样后的画面处理和查询协议审计，不含 Python 导入/进程启动，也不含模型视觉编码或回答。解码和画面处理是其子项，不能与完整墙钟相加。

每次先校验媒体 SHA，会预热操作系统文件缓存，因此不是冷盘测试。每源仅两次重复，时间变化只能用于这台本机、这批文件和这组配置。

应用待交付 RGB 缓冲上限3帧；FFmpeg 的参考帧、重排序和线程缓存不在这个计数中，另计进程 RSS 高水位。最多4个请求解码线程不等于整个进程只有4线程。

查询只交付已到达且符合原提交协议的帧。解码器内部为处理压缩依赖而进行的前读，不可冒充模型已接收未来画面；本实验验证交付及提交边界，不证明1倍速摄像头延迟。

首采样耗时不含前置媒体 SHA。当前 Windows Python 的 monotonic 时钟粒度以分析回执为准；接近该粒度的几十毫秒差异不作稳定首帧改善结论。

## 资源与执行纪律

仅本机 CPU，禁用 CUDA，不导入 Torch；不安装 Decord、不下载视频、不连接集群。总窗口30分钟，每 case 240秒硬超时/230秒内部守卫，RSS 上限1.5GiB，日志上限8MiB。任一像素、PTS、提交前缀或资源检查失败即结束，不自动重试。

准备、冻结、运行与分析输出采用独占创建，已有运行目录不能原地重跑。重复验证应使用新的实验标识和输出目录，保留本次证据。

输入身份一致证明的是输入协议保留，不是新的模型能力分数。CPU 输入加速不能直接代入历史 A800 的端到端成本，也不能称为 STC-Cacher 已接入；后者减少的是视觉网络计算，属于另一层改造。
