# 八个GPU小时以内的价值验证草案

2026-10-21，用户表示3—8小时预算可考虑，30—50小时过长。本文件是预算收紧后的准备方案，不是GPU或视频下载授权；持续进度只见实验总纲。

## 先纠正此前估算的含义

30—50 GPU小时是假设20个会话都需要4小时实际观察内容的整组参考估算，不是证明研究价值的必付门槛。上一轮217797已经共享视觉编码，724.413秒处理1426对/五银行/170答；不能再次把共享编码包装为尚未实现的新提速。FP32、1FPS、小画布保持，不能未经数值验收就承诺BF16或FlashAttention收益。

## 缩小首次决策的来源规模，不破坏时间跨度

本轮目标改为4个自然录制会话，每个约4小时实际观察内容，共96题（每会话24题）：8远期单事件、6跨事件/状态更新、6近期细节、4旧今联合。96题用于一次开发价值筛查，不称正式充分的泛化测评。四会话还必须按拍摄者/日期分组，来源组数如实报告；同一会话的题不能当独立视频复制样本量。

该规模尚未取得素材/标注，不是完成承诺。若现有官方纯视觉题不够，必须实际像素标注并复核；不能凭题目need_audio=False就当可答。超容量按实际原始序列Token数核验，保持原采样/分辨率和模型配置，不通过重复、补帧、缩小原模型上限制造。

96题分布和4来源名单在候选输出前冻结；保持小时级间隔。增加同一连续观察过程中的查询，不为每题重放全视频。以减少来源总观察时长节约GPU，不把所有会话缩回几分钟。

## 只留三条主要流式策略

固定一个视觉预算768 Token，不扫384/768双档：近期窗口、近期+既有固定种子均匀蓄水池、原M2森林。三组共享每个真实帧对的本次视觉计算，在线各自更新银行；不预存完整投影再回看未来，也不缓存四小时原特征装作在线记忆。768沿已完成开发证据选择，不在新输出后换预算。

已失败的S24不自动扩展或升级默认，A06/Q4等候选不全部加入本轮。完整历史只在工程/配置可运行的预先指定截点作参考，另有小型完整见证诊断和删旧控制；完整输入超限记不可运行，不计作错误。局部见证只能区分基础可读性，不能冒充整段原模型能力结果。

原始完整历史参考的显存/注意力成本不线性，须先做有界资源预检；不能把它当作已包含全部4小时整段prefill的固定开销。若资源预检不适配，保留不可运行事实与原因，不反复OOM。

## 总预算与停止点

按旧实测整进程每对摊销0.508秒，4×4小时约28800帧对，线性约4.06 GPU小时。旧值含五银行及170答，不是纯视觉计时；三银行可能更省但不预先声称。预留完整参考的短标定、固定控制与工程余量后，累计不超过8 GPU小时，1张A80080GB、4—8CPU、32GiB系统内存。不训练、不并发多卡、不重复扫参数。

准备时具体作业、分段、资源、累计已用和截止将绑定固定协议后向用户申请；没有本文件之外的自动加时。当前不提交新GPU。若实际吞吐使四会话不能在预算内完成，必须在提交正式运行前缩小预先冻结范围或报告不可行，不能运行后删除困难来源，不能静默扩预算。

这是快速因果重放和中途逐Token回答，不是把四个4小时会话都按1x播放。完整四会话1x至少16GPU小时，本预算不覆盖。若需要1x工程验收，只能另选短时片段并计入总额，不冒称完成小时级1x。

## 怎么决定下一步

主比较是森林相对同768的近期窗口和简单蓄水池，有没有旧事件的逐题纠正，近期是否损失；按来源组报告差异和不确定性。删旧消融与公开的同末不同首受控配对检验是否真的用到旧证据，诊断单列，不用总分替代。

若没有可靠的局部价值信号，承认固定首版未达本轮目标，不继续堆森林超参数；不能由四来源宣布所有记忆方法无效。若信号存在，下一段只验证一个由错误定位支持的改动，不自动升级20会话的昂贵规模。

Token压缩不是免评测的替代路线：S24已经是视觉Token压缩首版，现有结果无长期收益。若后续转压缩，应把问题缩成同旧证据的完整48/压缩表示读取与实际成本，用已冻结题和简单对照验证，再进入这套小时级一次比较。新方法尚未指定，不开始另起算法探索。
