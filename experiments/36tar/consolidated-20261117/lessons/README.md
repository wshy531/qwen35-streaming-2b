# 失败与教训

## 训练目标必须对应实际部署行为

首版剪枝连续注意力偏置能被损失优化，却未保证离散保留的Token更有用。硬选择前向、代理梯度和更新验收修补了执行目标，但训练来源上的CE改善仍不保证跨来源泛化。7B内容起点修补比弱起点配方更好，不代表它超过同起点的免训练方法。训练/初始化/完整视觉必须同表报告。

## 小头必须胜过同读取量的简单控制

减少历史Token不等于更快。完整视觉训练头直接接剪枝银行出现适配问题；后续排序修订可恢复分数，却收敛为全部历史读取，内容盲控制同样有效。没有证据时不把复杂网络作为默认部署路径。

## 旧证据存在不等于能够读出

独立历史读出及教师资格检查见两份随附报告。人工正确证据、模型原联合读取和异源历史分别作控制；通道logits会响应历史不等于答案正确依赖历史。相关配方已经有界结项，不自动扩训或改名重复探索。

## 原生LoRA：已完成流式主表，没有净收益

两种LoRA各训练1467视频10000官方原题，一轮、5,455,872可训练参数，视觉和底座原参数冻结。普通组使用前缀采样，LS组使用实际因果银行；训练题未与评测ID/媒体SHA重合。训练源以短片为主，不能冒充充分的分钟级长期记忆训练。

**解析器教训：** 初版把“B. A white sweater…”中的冠词A也当成选项，低估原模型；由此产生的初步增分判断已撤回。修正版优先识别开头明确选项、明确答案声明，格式不参与内容正确判定。9590输出全部重新核算，原模型三种视觉读取只剩4/1/2条截断解释未给出选项；它们单列未解析，分母保持959。`native-lora/outcomes.csv`仅含匿名样例/来源、方法及对错，不公开题面和答案键。`analysis.json`使用修正口径。

**执行教训：** 训练出现过无进展后从完整检查点恢复，16条更新记录复现；新增外部阶段心跳、超时抓栈、每25来源原子检查点。评测主表因墙钟保护停在948题，后补11题并精确复现10条旧输出，合并9590唯一回答。工程恢复不算能力贡献，不能无证据宣称原阻塞根因已修复。
