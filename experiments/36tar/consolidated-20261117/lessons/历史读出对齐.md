# 2B 独立历史读出对齐修订结果

本轮检验在同一个因果银行上，联合读出的额外监督能否帮助独立适配器用到真实旧内容，以及真实／异源历史的差值监督能否带来进一步收益。训练和开发按本轮固定的末轮权重比较。

**结论：教师资格成立，修订训练出现一般问答和当前题的局部收益，但没有明显改善历史题，也没有学出可靠的历史内容依赖。按预先约定结束本轮配方，不自动扩训或进入迁移。** 这里结束的是这一版训练配方，不是否定所有独立历史读出结构。

## 固定训练与开发协议（作业 224253）

两臂均完成两轮、每轮 297 次更新，总计 1,188 次更新和 13,156 次训练前向。每臂每轮为 2,371 道原题、2,985 个问时、194 条合格 H 监督、3,289 次前向。模型为冻结的 Qwen3.5-2B，只更新适配器的 4,210,690 个参数；沿用 1FPS、288×384、完整视觉 108 Token/帧对、LS864 的冻结快照。两臂从同一个旧初始权重开始，保持金标 CE、数据、顺序、选项排列、供体和原题权重一致。

近期画面仍经原语言网络读取；历史通过两个额外交叉注意力模块，在问题后缀处注入语言状态。它不是此前的二选一路由小头。本轮没有移动注入层、扩大模块或改记忆保存方法；教师监督发生在答案分布上，没有额外做中间视觉表征对齐。

| 条件 | 训练目标 |
| --- | --- |
| C0 旧普通适配器 | 冻结的已有末轮结果，按金标 CE 训练 |
| C1 真实教师对齐 | 金标 CE + 0.25 × 真实联合教师的选项 KL |
| C2 真实与异史差值对齐 | 同 C1，再加 0.1 × 真史与异史金标 log-odds 差值的 SmoothL1 损失 |

C1−C0 衡量在筛选 H 上新增教师监督的整体效果，其中软目标和额外监督权重同时发生变化。C2−C1 用于检验在同样教师 KL 和训练样本下，差值项是否额外改善真实历史读取。C2 对异史视图反传，两臂前向数量相同，计算成本可能不同。差值增大可能来自真实侧金标分数提高，也可能来自异史侧降分，两个方向单列。异史 H 不用原金标计算答案 CE。

## 结项决定

本轮按约完成教师资格、两臂训练和全量开发对照，未按结果改阈值、加轮数或挑 checkpoint。C1 的一般问答收益和 C2 的当前题收益如实保留；两者都没有补上主要历史能力缺口，且真实/异史敏感性仍弱。

按原结束条件，**归档这版答案分布／差值监督配方，不自动扩大训练、做 7B 迁移或叠加剪枝。** 原拟的 StreamingBench150＋短片60外部回归不启动，原因是其先决条件“真实 H 读取有实际改善”未建立；这两臂不再作为无限待测候选挂起。若后续重新立项，应改变并验证历史表示接入的具体假设，而不是继续给同一个目标换系数；须另定对照与预算。当前题的局部效果可以作为将来设计的参考，不能包装成已成功的长记忆机制。
