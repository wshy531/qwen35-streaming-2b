## 2. 剪枝训练修补

冻结 Qwen3.5-2B，仅更新 69,697 参数的视觉评分器。此前已经将连续注意力偏置的间接优化改为面向实际二值保留的训练；本阶段继续检查长期记忆反传、分段重算和训练退化。分段重算核查包括同设备合并、梯度与重复控制，不能把预检当泛化训练成绩。

更新验收版使用 1,237 道短片训练题和 1,114 道较长训练题。共提出 270 次更新，接受 141 次、撤销 129 次；撤销同时恢复评分器参数和优化器状态。验收只使用训练侧损失，不读取测评标签，亦不保证所有测试都改善。相关实现位于 `source/2b-training-repair-v1/`、`source/2b-stream-prune-repair-v1/` 及 `source/2b-delayed-recompute-v2/`。

## 3. 历史收益头

固定 1,114 道训练题，对银行四个历史节点的 16 种子集、两种选项排列评分。监督是“正确选项归一化概率相对近期路径的变化”，不是只看最终是否答对。两个排列取平均；它衡量当前冻结回答模型的读取收益，不是人工语义相关性标签。

在 CPU 上拟合内容可见/盲历史两种收益头 20 轮，2B 底座不更新。选择后仍以真实视觉特征作答。原先最多两节点的选择器与这次 16 子集收益训练需区分；不同头不能因都叫“小头”就混为一个版本。

## 7. 验证与下一步

在本目录执行：

```bash
python -I -B verify.py
```

仅标准库，无 GPU/网络。检查源码快照 SHA、Python 语法、全包文件哈希和718条匿名对错记录，重新汇总为20个方法结果；对应作业220559/220558/220931。它验证公开记录的一致性，不独立重跑模型、不替代原始视频审核，也不能从匿名对错反推出原标签。

后续优先按复用账本补统一开发口径缺项，再比较剪枝/LS 与历史收益选择；方法冻结后打开新短片60验证。近期保护、历史选择和训练验收继续作为候选，不默认宣称已解决实时感知干扰。不为凑目标持续扩容。搭档 PR #8 的开放问答判读属于另一协议，单列保留。
