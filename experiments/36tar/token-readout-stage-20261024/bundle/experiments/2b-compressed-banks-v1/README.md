# 有界银行与视觉压缩组合：P3接口准备

持续进度只见实验总纲。本目录为独立实验适配，不覆盖搭档和已冻结实验。

九臂为M0/M2/A06/LS各full48、change24，以及M0_odd24简单压缩控制。候选选择和旧事件阈值固定，事件描述子一律从完整48投影求均值，各臂共享相同边界，防止压缩同时改变事件分段。

## 已实现的接口

- 无完整档案、无持续观察语言KV。银行最多384视觉Token；选择器只保上一完整对，问答新建临时混合状态并释放。
- M0按384Token淘汰，48输入保8对、24输入保16对。M2/A06/LS近期按192Token计数，分别4或8对。
- 原M2/A06闭合森林预算144、开放节点预留48，合并函数及选择排序保持原版。24输入的开放节点仅24，所以最大常用量为360而非强行填满384；该空余量显式保留，不另调配额。LS共享历史预算192不变。
- 单帧对48/24都使用点时间标签；跨对融合才用区间与compressed memory标签。空间选择不再仅因不足48而被额外文字包装。旧48标签保持一致。
- 所选原坐标/原值不重编号。24银行不自动补零或重复成48，固定单会话输入长度并拒绝混用。
- Session._encode返回选择索引、48变化分数、冷启动、边界与时间；未积累日志列表。记录预处理、视觉、选择与银行更新、总帧对时间；各银行更新时间独立计数，评分计算共享部分明示。

## 内存边界

2048维FP32时，384Token的特征/mass/coords张量为3156480字节。change需另计上一对393216字节；事件策略还需8192字节描述子，Python对象和元数据另计。多臂进程物理共享的选择器/描述子只分配一次，独立部署成本按各臂需求分别归账，不能把同384视觉预算叫同总内存。

导出返回副本；问答检查银行摘要和选择器摘要均不变。来源结束clear释放节点、上一对与描述子。发生中途更新异常后银行整体标失败，禁止继续读取；不承诺跨九臂回滚事务。

## 本地验收

preflight.py：三种事件日程、864次M2/A06/LS full48逐步与冻结旧实现的节点值/来源摘要回归；24输入容量、导出隔离、固定尺寸拒绝、2048维计账、303查询九臂2727布局。最大输入706Token，无截断。

tiny_session_check.py：22真实RGB帧进入随机微型模型，11次视觉调用（含只查询孤帧快照），9臂独立逐Token问答后继续输入；银行与选择器不变、非法续接拒绝、close释放全部状态。

这些是接口证据，不是2B质量或端侧速度证据。CPU微型模型计时只验证计时路径可运行，不外推真实速度。

## 运行协议与证据边界

evaluate.py/run_eval.sh为九臂主比较入口，2727答/21816生成/3981共享编码/1载入上限，96MiB日志；freeze.py绑定输入/评分/129源码和1212旧full48参考。相同画面覆盖控制与独立成本测量不包含在此主作业，两地CPU与冻结SHA通过、具体GPU获批后才能提交。实际运行状态只看总纲。prepare.py/build_session.py是本次生成工具，输出已创建后不能直接重跑覆盖后续手工适配；正常使用已验收源文件。
