# 长期记忆是否值得采用：测评修订草案

2026-10-21。状态：设计与来源核验，不是数据已取得/标注完成，不是GPU授权。持续进度只见实验总纲。

## 已有证据不足，不能继续用场景设想补足

原六源最长输入13680 Token，模型配置262144，只有约5.22%；本地已有池最长视频613.35秒。这些资料适合测试局部可读性，却不具备证明突破完整上下文容量的条件。把旧32768工程保护叫原模型极限、重复播放或任意拼接无关片段，都不能替代真正长的自然输入。

刚完成的217797也没有建立长期收益：人工延迟六题M0-384/M2-384/M0-768/M2-768/S24-384分别3/3/4/3/3。扩容量及空间24首版没有修复目标旧顺序。更大近期窗口多对施工顺序，但原见证不在其窗口，说明仅答对不能证明用了旧证据。S24与M2同384的支持16题各8，但存在1纠正1损失，不是逐题等价。结论限于旧开发集，不宣布整个记忆方向无效。

## 两种主张必须分开检验

1. **有限资源下更有用**：即使原模型理论装得下，实际给定设备内存/响应约束时，记忆方案在可运行条件下提供更好的质量—成本组合。必须先选具体设备或给出已测资源曲线；不能把任意384额度直接叫端侧实际限制。全模型权重、主状态、银行、问答临时张量、CPU/磁盘历史与读取成本全部计入。
2. **超过完整上下文仍能使用旧事件**：实际已到达原始输入序列超过冻结模型配置的上下文/位置支持，原完整拼接无法按相同协议运行，仍能依靠有界历史回答。不能降低原模型上限制造此条件。原完整拼接超限记“该条件不可运行”，不计作错误答案；它并非所有资源不受限原模型策略的能力上限。

第二项也不保证第一项。压缩输入更短、代码能跑，不等于答案更可靠。

## 数据规模与题目条件

小型接通段计划2个会话、每个约4小时实际观察内容、共24次中途问题；只验输入/标注与成本可行性，不作最终优势结论。按1FPS和每对48视觉Token，四小时视觉本身约345600 Token；正式准入仍按实际处理器布局核算，不按文件时长估计。缺段不能补黑帧或重复画面充时长；同日物理分片可按原时钟连续播放，间断明确记录，不把不同任务拼成一条自然因果链。

正式目标保留至少20个自然录制会话、160道有效问题，含小时级会话与实际超容量截点；先核真实素材能否支持，再冻结来源和数量，不声称现已完成。按拍摄者/日期分组划分开发与留出，同一人的20个片段不算20个独立拍摄者，统计以来源组聚合。EgoLife人数有限，须报告这一限制。

题目暂定64道远期单事件、48道跨事件先后或状态更新、32道近期细节、16道旧今联合；每题须有截点以前的视觉见证、时间、正确答案与歧义记录。远期题见证至少离开最大近期基线，并覆盖5—15分钟、15—60分钟、超过60分钟间隔。对只靠声音/字幕/常识的问题单列或不准入纯视觉层。没有视觉见证就不凭字幕标答案。

所有候选题在查看候选模型输出前记录。局部完整见证仍答不对的题保留为基础能力层，不拿它单独评价压缩损失；不得看森林输出再选择容易赢的题。独立人工复核尚缺人力，单助手题不能包装为多人标注；先将证据交给用户/搭档审核，复核前维持开发身份。

## 固定比较与必要记忆控制

同一视频只按过去到现在写入，不提前告知未来问题；提问后继续接收，独立问答分支不写回观察状态。模型忙时按既定有界队列处理，真实1x与快速因果重放分别报告。

完整历史参考（可运行截点）、相同预算近期窗口、相同预算近期+固定均匀蓄水池、冻结M2以及一个已冻结候选共同比较；不把完整历史超限算0分来抬高记忆准确率。原模型分块+摘要等更强策略若未跑，不能宣称打败所有原模型用法。两档预算是当前固定384/768的开发控制；端设备主预算须由实际设备容量/运行曲线在答题前冻结。

必要记忆控制分两类：自然题用删除旧证据的固定消融，分别报告变化与未变化，避免仅靠分布改变作因果结论；另设“结尾相同、早期事实不同”的受控配对，来源/剪接边界公开，作为机制诊断单列，不冒充自然连续长片。交换记忆只用于真值已知且语义匹配的受控配对，不能给自然视频交换一个不相干旧根就声称证明能力。

核心指标：旧事件逐题纠正/损失、近期退化、两段配对同时正确且随旧证据变化的比例、各时间间隔表现、按源聚合的不确定性、实际内存/磁盘/端到端延迟/观察更新/丢帧/答案陈旧度。所有条件相同、所有失败保留。超容量不可运行率与可运行题准确率分开，不混成单一准确率。

## 完成与停止条件

先完成数据/容量准入与小型接通，再做一次冻结正式比较；此期间不加新压缩器。若不能取得合格素材或不能建立必要旧证据的题，报告测评未就绪，不能再称本项目已证明长期记忆有价值。若测评合格但候选没有同预算收益或造成明显近期损失，报告候选未达目标，停止这版调参；任何下一算法需依据固定失败层另提一项假设。已有Q4读取与其他候选移至这次测评准备完成后的固定比较槽，不无限延期或插队试更多参数。
