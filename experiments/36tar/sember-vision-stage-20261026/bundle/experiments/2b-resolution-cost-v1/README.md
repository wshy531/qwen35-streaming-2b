# S-EMBER 两档分辨率与完整成本：一次固定探索

只读复用官方固定128视频/478题，0.5 FPS、FP32、16生成Token、auto4解码。
不补纯文字，不增加数据，不改正在运行的218526，不训练，不重开旧V1缓存。

M0、原M2、A06、LS分别比较：

| 条件 | 投影网格 | 每对保留 | 银行预算 |
|---|---|---:|---:|
| mid108：288×384完整 | 9×12 | 108 | 864 |
| high192：384×512完整 | 12×16 | 192 | 1536 |
| highchange108：384×512变化选择 | 12×16 | 108 | 864 |

另加M0_highuniform108作为等Token简单选择控制，总13条件/6214答。
192→108来自匹配现有864预算，不扫描保留比例；变化分数沿用原同位置余弦，
稳定排序，冷启动固定均匀108，保留原坐标，不学习新权重。108/192为56.25%，
并非旧实验的严格减半。事件描述子仍来自完整本分辨率投影，阈值不变；
分辨率可能改变事件边界，比较的是整个输入—记忆路径，不独断因果归因于剪枝。

完整高档按四近期对加四历史对等价容量分配；原M2/A06为4近期+1开放+3闭合，
LS为4近期+4共享。等Token高档用108一对的相同分配；不是把1536预算压回后
暗增保留帧数。M0完整8对，其他森林的来源覆盖随合并变化，不能声称帧集合完全相同。
变化选择额外上一完整192×2048 FP32特征1.5MiB，另有描述子/质量/坐标。
完整中档和高档没有独立变化臂时不持有上一完整特征；共享质量阶段与独立成本分开。

质量阶段按两档分辨率运行，各自只做一次连续解码和每新增帧对一次视觉前向，
同档共享视觉但问答独立，主状态KV不驻留。完整中档1912答必须复现218526对应
四组的生成IDs、文本、问题及上下文IDs摘要；不复现就停止，不放宽校验后继续。
本实验不重跑384×512全历史语言状态，不能称为原生完整上下文分辨率对照。

成本面板在输出前仅按来源SHA、视频时长及题型元数据固定12来源57题，
三个时长层各4来源、覆盖8题型，保留来源全部题。3个不相交块各4来源，
三种LS配置轮换运行次序，9个独立进程；不是三次重复同一个全集。
每个进程单独解码、预处理、视觉编码、更新和回答，不共享其他方法结果。
正式171答必须复现质量阶段同条件输出。成本结论只适用于LS面板，
不能推广为M0/M2/A06独立实测；多臂共享阶段峰值不当作单臂显存。

合计6385正式答+22预热=最多6407答、102512生成Token、35097视觉前向、
11次顺序FP32载入，同时一个模型；不存全视频RGB/完整特征档案。
