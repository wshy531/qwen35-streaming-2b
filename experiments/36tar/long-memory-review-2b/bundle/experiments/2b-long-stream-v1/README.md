# 长视频中途问答：固定开发验收方案

本目录用于检查真实自然长视频的持续输入、主状态续接/重置、外部记忆和中途回答。持续进度只读项目根目录《实验总纲.md》。不要运行旧输入01；本次冻结输入为02、启动脚本为 `run_eval_v2.sh`，提交须有本次明确GPU授权。

## 数据与问题

6段已有Ego4D自然视频，每段约7.5—8分钟；1FPS、等比补边192×256，实际采样2853帧。保留28道OVO原题；单人首轮审核16支持、11歧义、1在完整帧对截点尚未发生。另有6道人工开发题，证据距提问129—443秒，与原题分别评分。它们不是新增独立来源，也不是正式留出基准。

## 实际运行过程

解码器只暂存有限的待配对/当前/前视采样包。每两帧到达后，视觉编码一次，将同次投影写入主混合状态及可选银行。不会先编码整条视频再模拟在线。

在固定问题时刻停止输入，只让问答读取已经写入的完整帧对；未配成对的一帧显式报告，不用未来帧补齐。答案逐Token回调、问答分支随后释放，继续原观察会话直到视频结束。每问核对真实帧与已提交前缀指纹。

五组为：原模型完整已到达前缀、仅主状态、M0最近8对、M2事件森林、纯文字控制。主状态上限2048Token；两种银行均最多384视觉Token。M0/M2的历史问答只读取自己的银行。主状态重置会丢失主历史，但不会清空外部银行。

原模型独立进程保留已到达RGB，提问时重读整个前缀，其存储和重复计算成本明确记录。CPU像素预处理按对分块后顺序拼接，原模型视觉/语言计算仍使用一次完整前缀；6源短输入已逐位检查。最长本轮输入13680Token，保护上限32768，模型配置原生位置上限262144；不使用旧8192门槛人为制造原模型失败。
