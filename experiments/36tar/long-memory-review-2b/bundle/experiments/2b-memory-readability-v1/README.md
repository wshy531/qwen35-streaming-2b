# 旧记忆可读性诊断与文件实时调度

持续进度、授权、实际结果及候选顺序只读项目根目录的 `实验总纲.md`。本目录是独立实验，不修改默认模型或旧综合汇报。

## 要回答的问题

森林的来源范围包含旧事件，但模型没有因此多答对历史问题。来源存在并不代表细节仍可读。本实验只定位损失发生在哪一段，不把诊断方法包装成新记忆架构。

固定上一轮全部六个人工开发题，问题、选项、标签与查询时刻不改。由前轮输出产生前记录的画面见证，指定实际森林中覆盖见证的旧节点。指定节点是人工诊断工具，不能称自动检索。

| 条件 | 输入 | 用途 |
|---|---|---|
| A | 与选定旧节点覆盖范围相同的全部未压缩成对特征 | 检查这段原证据在成对读取协议下是否可答 |
| B | 选定的实际压缩旧节点 | 检查压缩节点单独是否可读 |
| C | A加原来的近期四对 | 检查近期内容是否影响原证据读取 |
| D | B加完全相同的近期四对 | 检查近期内容是否影响压缩节点读取 |
| E | 查询前全部已提交的未压缩成对特征 | 区分选择范围与完整成对读取路径的影响 |
| F | 查询时原有完整M2银行 | 检查是否复现前轮的六条生成序列 |

A/B/C/D共24个主条件，E/F共12个必要参照。六题全部保留，包括原来的成功与失败。严格单字母评分沿用原评分器，格式错误不事后改成正确。

## 能说明什么

- A正确、B错误：支持当前压缩表示及其位置适配存在读取损失，需要继续区分二者，不能断言全是特征平均造成。
- B正确、D错误：支持相同旧节点加入近期内容后发生干扰，可以优先考虑选择相关证据。
- D正确、F错误：可能是其他旧节点的干扰，不能仅归因于近期画面。
- A错误：选定未压缩上下文没有答对；可能涉及所选范围、表示、时间关系或基础识别，不能统称压缩失败。
- E错误而旧原生完整输入正确：还存在成对视觉/读取协议的差别，不能用压缩解释全部差异。
- F不能复现：先报告复现边界，不把旧、新运行的差异直接当作可靠因果证据。

只有六个已打开开发样例，不作通用准确率、稳定优越性或自动检索能力结论。一次固定对照结束后分析并收束，不扫描问题、阈值、节点组合或提示词。

## 实现与资源边界

`evaluate.py`按原顺序重新采样、逐对编码、更新原M2银行；到固定查询截点后读取六种上下文。为诊断而暂存该来源的完整未压缩特征，各来源结束后释放。这是额外诊断开销，不能算作有界流式候选。算法、阈值、压缩坐标策略和模型权重不改。

固定FP32，1次预训练模型载入，1350次视觉编码，最多36答/288生成Token。上下文保护32768、视觉Token保护16384、节点保护256，读取预填充块512，生成上限8。六份有限银行快照总量上限24MiB；不保存全历史RGB或全历史特征快照。总作业30分钟，worker1500秒；观察RSS保护20GiB、GPU allocated保护32GiB。

## 文件实时部分的适用范围

`clock_input.py`复用既有PTS节拍与容量1最新帧槽。读帧线程只处理像素；单消费者拥有模型状态。提问截止先于新帧消费，答案只读取当时已提交的完整帧对；模型忙时旧采样帧允许被新帧替换，记录丢帧和答案滞后。每个运行独立记录实际收到的帧，不能强行把不同丢帧的运行当同输入能力比较。

`test_clock_input.py`检查逾期/同刻问题、EOF、生产者或消费者故障与退出。`cpu_clock.py`使用真实视频的短窗口、正常和显式慢问答条件，以及随机微型模型。它只验证调度工程，不证明真实2B的8分钟1倍播放质量。

`cpu_diagnostic.py`与`cluster_preflight.py`构造36种布局并做短随机读取。长上下文仅构建，不在登录节点运行预训练模型或长前向。任何实际GPU作业仍须依照用户提供的超算规范另获明确授权。
